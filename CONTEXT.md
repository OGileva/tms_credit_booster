# CONTEXT — AI-first каталог тест-кейсов

---

## Назначение

QA работает с каталогом через AI-агента: прикладывает существующие кейсы для массового добавления или описывает требуемую выборку естественным языком. Git обеспечивает общую историю и распространение изменений.

---

## Модель данных

Markdown-файл удобен для Git diff, code review, поиска и работы разных агентов. Папка определяет продукт и функциональный раздел. Front matter хранит ID, статус, теги и связи с задачами. Пользовательский экспорт остаётся независимым от формата хранения.

---

## Границы

- Каталог хранит утверждённые формулировки, но не доказывает production-поведение.
- AI выбирает только существующие кейсы и объяснимые фильтры; он не дополняет выборку вымышленными проверками.
- Изменение кода является основанием предложить регресс, но не доказательством изменения runtime-поведения.
- Commit и push остаются контролируемым действием QA.
