# Внесение изменений

1. Не редактировать `generated/index.json` вручную.
2. Создать ветку от актуальной основной ветки.
3. Добавить кейсы через `_templates/test-cases.xlsx` или `qa-cases new-pack`.
4. Сохранить файл в `cases/<product>/<function>/`.
5. Проверить уникальность ID и качество формулировок.
6. Выполнить `make check test index`.
7. В MR перечислить задачу, функционал и диапазон ID.

Merge Request не должен содержать выгрузки из `exports/`, временные файлы Excel, секреты или персональные данные.
