# Регламент работы с репозиторием тест-кейсов

- **Status:** draft
- **Date:** 2026-10-20
- **Owner:** QATL

---

## Назначение

Регламент задаёт единый порядок массового добавления, ревью, хранения и выборки ручных тест-кейсов.

---

## Роли

| Роль | Ответственность |
|---|---|
| QA | Создаёт и обновляет кейсы, выполняет локальную проверку |
| QATL | Подтверждает структуру функционала и состав критичных suites |
| Reviewer QA | Проверяет достоверность, покрытие и формулировки |

Технические права push/merge задаются настройками Git-сервера и не определяются этим документом.

---

## Добавление большого набора

1. Создать ветку.
2. Выполнить `qa-cases new-pack --product <product> --function <function> --name <task>`.
3. Заполнить строки в Excel без добавления колонок и листов.
4. Использовать стабильные ID и атомарные нумерованные списки.
5. Выполнить `qa-cases validate`.
6. Обновить `generated/index.json` командой `qa-cases index`.
7. При необходимости обновить suite.
8. Передать изменения на QA-review через Merge Request.

---

## Выборка

### По функционалу

```bash
qa-cases select --product credit-booster --function payments --output exports/payments.xlsx
```

### По набору регресса

```bash
qa-cases select --suite release-critical --output exports/release-critical.xlsx
```

### По задаче или термину

```bash
qa-cases list --search CBN-1234
qa-cases select --search таймаут --output exports/timeouts.xlsx
```

---

## Review перед merge

- Все ID уникальны и стабильны.
- Все пять полей заполнены.
- Предусловия, шаги и результаты атомарны и пронумерованы.
- Ожидаемые результаты подтверждены требованиями или реализацией.
- Учтены позитивные, альтернативные, негативные и граничные сценарии.
- Обновлён состав regression suite, если изменение затронуло риск набора.
- В репозитории нет экспортов, временных файлов, секретов и персональных данных.

---

## Merge Request

В описании указать:

1. задачу или основание изменения;
2. продукт и функционал;
3. добавленные, изменённые и удалённые ID;
4. suites, на которые повлияло изменение;
5. результаты `make check test index`.
