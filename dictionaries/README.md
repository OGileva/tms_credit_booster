# Словари

Словари определяют значения, которые можно использовать в метаданных тест-кейсов.

## `tags.json`

В файле перечислены допустимые теги. У каждого тега есть:

- `id` — каноническое значение, которое сохраняется в кейсе;
- `aliases` — варианты написания, принимаемые при импорте и поиске;
- `description` — краткое описание назначения тега.

Канонические теги проекта записываются на русском языке. Например, `regression` может быть alias для канонического тега `регресс`.

Перед использованием нового тега:

1. добавьте его в `dictionaries/tags.json`;
2. укажите понятное описание;
3. добавьте aliases, если пользователи могут вводить другие варианты;
4. выполните `qa-cases validate`.

Не создавайте два тега с одинаковым смыслом без необходимости: это усложнит поиск и экспорт.
