# AGENTS.md — suites

Suites задают воспроизводимые наборы без копирования исходных кейсов.

---

## Правила

- `smoke` — короткая проверка доступности критического пользовательского пути; не считать полным регрессом.
- `release-critical` — обязательные проверки критичных рисков релиза.
- `full-regression` — все активные исходные кейсы.
- Предпочитать стабильные ID для точечных наборов и glob/functionalities для целых областей.
- Для каждого изменения suite в MR объяснить причину включения или исключения.
- Пустой smoke или release-critical означает, что набор ещё не утверждён; не заполнять вымышленными кейсами.
