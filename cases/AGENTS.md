# AGENTS.md — cases

`cases/` — единственный редактируемый источник тест-кейсов.

---

## Правила

- Путь: `cases/<product>/<section path>/<ID>.md`.
- Файл кейса лежит непосредственно рядом с `section.json`.
- Один кейс не копируется в другой раздел или suite.
- Для включения в регресс используется тег `regression` или правило suite.
- Не переносить опубликованный кейс между разделами без проверки ID-префикса и внешних ссылок.
- После изменений выполнить `qa-cases validate` и `qa-cases index`.
