# Внесение изменений

Порядок добавления документации, импорта кейсов и выгрузки описан в [README.md](README.md). Правила AI-агента находятся в [AGENTS.md](AGENTS.md).

Работать в отдельной ветке от актуальной основной ветки.

## Review

- Раздел выбран однозначно.
- ID соответствует префиксу раздела и уникален; опубликованные ID сохранены.
- Название кейса не дублируется внутри раздела.
- Обязательные поля заполнены; предусловия, шаги и результаты атомарны и последовательно пронумерованы.
- Теги существуют в словаре; канонические значения русские (`критичный`, `регресс`, `смоук`). Уровень критичности хранится отдельно в поле `criticality` (`critical`, `medium`, `low`).
- Ожидаемые результаты подтверждены требованиями или реализацией.
- Документация размещена в `docs/` и добавлена в оглавление; ссылки из кейсов ведут на существующие документы.
- В Git не попали исходные вложения, экспорты, временные файлы, секреты или персональные данные.

## Проверки и коммит

```bash
make check test
git diff --check
git status --short
```

После review QA выполняет commit и push; агент делает это только по прямому запросу. В commit/MR указать задачу, изменённые документы либо раздел и диапазон ID кейсов, теги и влияние на регресс, смоук и критичные проверки.
