# Шаблоны

В этой папке находятся примеры файлов для работы с тест-кейсами.

## Файлы

- `test-case.md` — пример блока тест-кейса в формате Markdown. Такие блоки хранятся в групповых файлах разделов.
- `import-test-cases.xlsx` — пример таблицы для импорта. После импорта рабочие данные хранятся в `cases/`.

## Колонки для импорта

Обязательные колонки:

- `Название` или `Name`;
- `Предусловия` или `Preconditions`;
- `Шаги воспроизведения` или `Steps`;
- `Ожидаемый результат` или `Expected Result`.

Опциональные колонки:

- `Описание` или `Description`;
- `Тег`/`Теги` или `Tag`/`Tags`;
- `Критичность` или `Criticality` со значением `critical`, `medium` или `low`.

Колонку `ID` можно не добавлять. Если она есть, CLI игнорирует её значение и назначает ID автоматически.
