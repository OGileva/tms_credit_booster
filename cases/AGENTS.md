# AGENTS.md — cases

`cases/` содержит единственные редактируемые источники тест-кейсов.

---

## Правила

- Структура: `<product>/<function>/*.xlsx`.
- Перед созданием кейсов изучить задачу, требования и актуальный код соответствующего продукта.
- Один XLSX: один лист `Тест-кейсы`, пять канонических колонок, без служебных листов и формул.
- Не дублировать кейс в другом файле ради регресса. Добавить его ID или правило в `suites/`.
- Не переносить кейс между функционалами без проверки ссылок в suites.
- После изменений выполнить `qa-cases validate` и `qa-cases index`.
