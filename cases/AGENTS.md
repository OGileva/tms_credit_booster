# AGENTS.md — cases

`cases/` — единственный редактируемый источник тест-кейсов.

---

## Правила

- Путь: `cases/<product>/<section path>/<групповой файл>.md`.
- Групповой файл лежит непосредственно рядом с `section.json`; внутри него каждый блок имеет собственный числовой ID.
- Один кейс не копируется в другой раздел или набор.
- Для включения в регресс используется русский тег `регресс`, для критичного набора — `критичный`; уровень критичности хранится в поле `criticality`.
- Не переносить опубликованный кейс между разделами без проверки числового ID и внешних ссылок.
- После изменений выполнить `qa-cases validate` и `make test`.
