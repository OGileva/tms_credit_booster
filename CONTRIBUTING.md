# Внесение изменений

1. Создать ветку от актуальной основной ветки.
2. Попросить AI-агента добавить приложенные кейсы в указанный раздел или выполнить `qa-cases import`.
3. Проверить diff Markdown-файлов: данные, ID, теги, атомарность шагов и ожидаемые результаты.
4. Выполнить `make check test index`.
5. Не коммитить исходные вложения, `exports/`, секреты и персональные данные.
6. В commit/MR указать задачу, раздел, диапазон ID и влияние на regression/smoke.
